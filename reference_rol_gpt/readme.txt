【はじめに】
「The Ruins Of The Lost Kingdom」は
「常闇の遺跡アビスターナ」で繰り広げられる物語を描く3DアクションRPGです。

本ゲームの最新バージョンはTOMOSHIBI.NET(http://www.tomoshibi.net/)にて入手可能です。


【最低動作環境】
OS             Windows98/Me/2000/XP
DirectX        DirectX8.1以上がインストールされている環境 
CPU            動作周波数466MHz以上(PentiumIII 800MHｚ以上推奨) 
SYSTEM MEMORY  64MB以上(512MB以上推奨) 
VIDEO CARD     DirectX8.1に対応したビデオメモリ16MB以上搭載のビデオカード
               nVIDIA: RIVA TNT2以降のビデオカード推奨
               ATI   : Radeon以降のビデオカード推奨
               Matrox: MilleniumG400以降のビデオカード推奨
SOUND CARD     DirectSound対応のサウンドカード 
GAME PAD       ２軸７ボタン以上のゲームパッド推奨 


【はじめかた】
フォルダ内の「青灯アイコン」をダブルクリック(実行)してください。
初回起動時には必要な環境設定を行います。
環境設定の詳しい内容は別途ヘルプを参照してください。

【操作方法】
----------------------------------------------------------------------------------------------------
・キー説明
----------------------------------------------------------------------------------------------------
　Zキー			　…　武器攻撃
　Xキー			　…　魔法攻撃
　Cキー			　…　アクション
　Vキー			　…　ジャンプ
　SHIFTキー		　…　アクティブメニュー
　SPACEキー		　…　ポーズメニュー
　A,Sキー		　…　カメラ回転
　ESCキー		　…　システムメニュー

----------------------------------------------------------------------------------------------------
●基本操作
----------------------------------------------------------------------------------------------------

▼キャラクタの移動
　方向キーを入力することでキャラクタを自由に移動させることができます。

▼カメラ回転
　カメラボタンを入力することでカメラの回転を行うことができます。
　またカメラボタンを２つ同時に押すことでカメラの位置を
　操作キャラクタの後方に素早く移動させることができます。

▼武器攻撃
　武器攻撃ボタンを入力することで武器による攻撃を行います。
　連続で入力したり、魔法攻撃と交互に入力することで様々な攻撃を行うことができます。
　また、武器攻撃ボタンを一定時間押して放すことで武器に付与したスキルを発動することができます。

▼魔法攻撃
　魔法攻撃ボタンを入力することで魔法による攻撃を行います。
　連続で入力したり、武器攻撃と交互に入力することで様々な攻撃を行うことができます。
　また、魔法攻撃ボタンを一定時間押して放すことで指輪に付与したスキルを発動することができます。

▼ドッジロール
　方向キーを押しながらアクションボタンを入力することで発動します。
　敵の攻撃を回避するのに有効です。

▼ジャンプ
　ジャンプボタンを押す、またはアクションボタンをすばやく2度押すことでジャンプをすることができます。
　ジャンプ中に攻撃ボタンを入力することで地上同様に攻撃を行うことができます。

----------------------------------------------------------------------------------------------------
●特殊操作(パッシブスキル習得/設定時のみ使用可能)
----------------------------------------------------------------------------------------------------

▼ガード
　全てのキー入力を行っていない場合自動的に発動されます。
　但し、後方からの物理攻撃はガードできません。

▼受け身
　ダウンモーション中にアクションボタンを入力することで受け身を取ることができます。

▼緊急着地
　ジャンプ中にジャンプボタン、またはアクションボタンを入力することで素早く
　地面に着地する事が出来ます。

▼ガード中の特殊操作
　ガード中に武器攻撃ボタン：特殊攻撃
　ガード中に方向キーを相手方向に入力しながらアクションボタン：敵の横方向に回り込む特殊動作
　ガード中に方向キーを自分方向に入力しながらアクションボタン：後方に回避する特殊動作
　また「緊急着地」「受け身」後の着地中、「ダウン中」にも同様の動作を行うことができます。

▼スキル発動中の特殊操作
　一部のスキルでは発動中に武器攻撃ボタンなどを入力することで追加攻撃を行うことができます。

▼フォロースルーキャンセル
　攻撃モーションのフォロースルー(隙)時にタイミング良く
　アクションボタンを押すと隙無く回避動作が可能です。
　回避動作は「ガード中の特殊操作」の動作と同等の物となります。
