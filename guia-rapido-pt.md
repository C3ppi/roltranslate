# Guia rápido em português — The Ruins Of The Lost Kingdom (v7.02)

## Sobre o jogo

RPG de ação em 3D ambientado nas ruínas de Abistana, um lugar envolto em trevas. A versão do arquivo é 7.02. O manual original informa que o jogo foi feito pelo grupo Tomoshibi.

## Controles padrão

| Tecla | Ação |
|---|---|
| Setas | Mover o personagem |
| Z | Ataque com arma |
| X | Ataque mágico |
| C | Ação |
| V | Pular |
| Shift | Menu de ações rápidas |
| Espaço | Menu de pausa |
| A / S | Girar a câmera |
| Esc | Menu do sistema |

Os controles podem ser alterados nos arquivos `input00.ini` a `input03.ini` ou na configuração do jogo.

## Mecânicas básicas

- **Movimento:** use as setas para movimentar o personagem livremente.
- **Câmera:** use os comandos de câmera para girá-la. Pressionar os dois comandos juntos reposiciona a câmera rapidamente atrás do personagem.
- **Combos:** alterne ou repita os ataques de arma (Z) e magia (X) para executar sequências diferentes.
- **Habilidades equipadas:** segure Z ou X por um tempo e solte para ativar, respectivamente, a habilidade da arma ou do anel.
- **Esquiva:** pressione uma direção junto com C.
- **Pulo:** pressione V ou toque C duas vezes rapidamente. É possível atacar no ar.

## Habilidades passivas especiais

Estas ações só ficam disponíveis quando a habilidade passiva correspondente foi aprendida e configurada.

- **Defesa automática:** ocorre quando você não está pressionando nenhum comando. Ataques físicos pelas costas não podem ser defendidos.
- **Recuperação no chão:** pressione C durante a animação de queda.
- **Aterrissagem rápida:** durante o pulo, pressione V ou C.
- **Ações durante a defesa:** Z executa um ataque especial; C junto com a direção do inimigo contorna o adversário; C junto com a direção oposta recua.
- **Cancelar recuperação do ataque:** pressione C no momento certo durante o fim do movimento de ataque para emendar uma esquiva.

## Observação sobre a tradução

Este guia traduz as instruções de controle presentes no `readme.txt` do pacote. Os diálogos, menus e textos internos continuam em japonês: eles estão dentro dos arquivos `.cr`, que usam um formato proprietário ainda não decodificado.
